# CODE ROOM — 마지막 컴파일

Java Swing 구현 전 게임 흐름을 확인하는 HTML 프로토타입입니다. 외부 패키지, 이미지 다운로드, API 키 없이 실행됩니다.

## 실행

`index.html`을 브라우저로 열거나, 저장소 루트에서 아래 명령을 실행한 후 http://localhost:4173 에 접속합니다.

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory prototype
```

## 플레이

1. 처음 받은 종이의 Java 코드를 읽고 출력값을 추리합니다.
2. 방의 서랍장을 눌러 네 자리 암호를 입력합니다.
3. 서랍에서 얻은 새 종이를 읽고 벽의 3×3 다이얼을 풉니다.
4. 하단 인벤토리에서 황동 열쇠를 선택하고 출입문을 누르면 탈출합니다.

방이 화면 전체를 채우며, 인벤토리를 선택하면 왼쪽에 손에 든 단서가 바뀝니다. 종이는 접어둘 수 있고 같은 인벤토리를 누르면 다시 펼쳐집니다. 세로로 긴 화면에서는 방을 좌우로 밀거나 화살표로 이동합니다. 작은 화면에서 암호 입력 중 메모를 선택하면 입력창을 닫고 메모를 펼치며, 다시 장치를 열면 입력값을 복원합니다. 힌트, 오답 재시도, 다시 시작, 키보드 조작, 작은 화면 레이아웃을 지원합니다. 브라우저 저장소를 사용할 수 있으면 진행 상태를 저장합니다. Java 코드를 실제로 실행하거나 AI API를 호출하지 않습니다. 시간은 페이지가 닫혀 있는 동안도 포함한 시작 이후 경과 시간입니다.

## 파일 구성

- `index.html`: 게임 화면과 대화상자
- `style.css`: 화면, 종이, 인벤토리, 반응형 스타일
- `room.js`: 직접 제작한 Canvas 픽셀 서재 및 장치 상태
- `game.js`: 단서, 잠금 판정, 아이템, 저장, 탈출 흐름

## 검증용 정답 (스포일러)

- 첫 메모: `2312`
- 격자 메모: `423 / 312 / 133`
- 마지막 문: 황동 열쇠를 선택한 상태로 문 클릭

이 HTML은 클라이언트에서 정답을 판정하는 시연용입니다. 기존 Java Swing 기획서 및 구현 기술 선택을 대체하지 않습니다.
