# CODE ROOM — HTML 프로토타입 디자인

## 범위와 구성

이 문서는 `index.html`, `style.css`, `room.js`, `game.js`에 구현된 브라우저 프로토타입을 설명한다. 향후 Java Swing 제품의 명세가 아니다. 별도 빌드 도구 없이 HTML·CSS·JavaScript·Canvas로 실행하며 Java 코드 실행이나 AI 호출은 하지 않는다.

**방 자체가 화면이다.** 방이 `100dvh`를 채우며 웹사이트 헤더, 페이지 여백, 사이드바, 푸터, 바깥 카드로 감싸지 않는다. 위쪽 상태·시간·도움말·재시작은 방 위에 얹힌 작은 게임 HUD다. 원본 Canvas 그림은 480×300 좌표계를 960×600 버퍼에 그려 확대하며 보간을 끄고 픽셀 경계를 유지한다. 초록 벽, 목재 가구, 책과 식물, 비 오는 창문, 황동 잠금 장치가 서재를 구성한다. 비네트는 가장자리를 어둡게 해 방 안의 물건에 시선을 모은다.

한국어 UI는 Apple SD Gothic Neo·Malgun Gothic·sans-serif, 코드와 숫자는 Menlo·Consolas·monospace를 사용한다. 코드에는 줄 번호와 키워드·숫자·출력 메서드 색 구분이 있다. 모서리는 대부분 2–4px로 작게 처리하고 얇은 테두리, 제한적인 그림자, 선형 SVG 아이콘을 사용한다.

## 손에 든 단서와 인벤토리

단서는 왼쪽 아래에 약간 기울어진 종이 오버레이로 놓인다. 접힌 귀퉁이, 메모 번호, 제목, Java 코드, 답의 형태, 짧은 주석으로 읽는 순서를 만든다. 아래의 힌트는 사용자가 펼치는 `details`다. ‘접어두기’로 방을 넓게 볼 수 있고 인벤토리의 물건을 선택하면 다시 펼쳐진다.

하단 중앙에는 다섯 칸 인벤토리가 고정된다. 시작 메모, 격자 메모, 황동 열쇠가 순서대로 채워지며 선택한 칸은 황동 테두리와 밝은 녹색 바탕으로 표시한다. 사용 완료 표시는 체크 아이콘과 종이의 `SOLVED` 문구로 함께 전달한다. 방의 물건은 투명한 HTML 버튼으로 조작하며, 호버·키보드 포커스에서 테두리와 설명이 드러난다.

## 퍼즐과 상태 변화

1. 접힌 메모의 배열·반복문을 읽어 네 자리 서랍 암호를 입력한다. 정답이면 서랍 그림이 열리고 격자 메모를 얻는다.
2. 격자 메모의 출력 결과를 벽의 3×3 다이얼에 입력한다. 정답이면 다이얼 그림과 표식이 바뀌고 황동 열쇠를 얻는다.
3. 인벤토리에서 열쇠를 선택한 상태로 출입문을 누르면 문이 열리고 탈출 시간·해제한 장치 수가 표시된다.

획득 시 짧은 토스트, 인벤토리 갱신, 장면 설명이 함께 나타난다. 빈 입력과 오답은 입력 패널 안에서 설명하며 시도 횟수 제한은 없다. 입력 초안은 패널을 닫아도 유지한다. 진행 단계·선택 물건·시간 등은 가능한 환경에서 localStorage에 저장한다. 재시작은 확인 대화상자를 거친다.

## 좁은 화면과 접근성

방의 너비는 `max(100%, 140dvh)`로 유지하고 좁은 화면에서는 가로 스크롤로 카메라를 이동한다. 700px 이하에서는 좌우 이동 버튼과 안내가 나타나며, 종이와 인벤토리는 화면에 고정된다. 퍼즐 패널은 중앙으로 이동하고 열린 동안 종이를 숨긴다. 종이·패널 내부는 필요하면 스크롤되어 긴 내용을 읽을 수 있다.

Canvas는 장식으로 숨기고 실제 조작은 이름이 있는 HTML 버튼·입력 필드로 제공한다. 선택 상태는 `aria-pressed`, 입력 오류는 `aria-invalid`, 단서·장면·오류 안내는 라이브 영역으로 전달한다. 키보드 포커스를 황동색 윤곽선으로 표시하고 패널을 열 때 입력으로, 닫을 때 원래 요소로 돌린다. Escape로 퍼즐을 닫을 수 있으며 격자 입력은 자동 다음 칸 이동과 여러 숫자 붙여넣기를 지원한다. 도움말·재시작·완료에는 네이티브 `dialog`를 사용한다. CSS는 reduced-motion 환경에서 전환을 제거한다. 다만 좌우 이동 버튼은 JavaScript에서 smooth 스크롤을 요청하므로 완전한 모션 감소 준수까지 보장하는 명세는 아니다.
