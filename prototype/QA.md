# 프로토타입 검증 기록

2026-10-27, Aside Browser에서 확인.

## 게임 흐름

- 초기 종이 1개와 잠긴 서랍·다이얼·문 표시.
- 서랍의 빈 입력과 오답 안내. `2312` 제출 시 격자 메모 1개 획득.
- 격자 다이얼의 빈 입력과 오답 안내. `423 / 312 / 133` 제출 시 황동 열쇠 획득.
- 인벤토리 선택에 따른 단서 교체 및 종이 접기·다시 펼치기.
- 열쇠 획득 전 출입 불가, 열쇠가 아닌 종이를 선택한 상태에서 출입 불가.
- 황동 열쇠 선택 후 문 클릭 시 탈출 완료 표시.
- 다시 시작하면 초기 물건·잠금·타이머로 복원.
- 새로고침 후 풀이 단계·선택한 물건 복원.

## 화면 및 조작

- 1440×900: 방이 전체 뷰포트를 채우고 웹 헤더·페이지 외곽 여백 없이 표시.
- 중앙 서랍은 왼쪽 종이에 가려지지 않음. 하단 인벤토리 표시.
- 390×844: Aside 내 동일 출처 iframe을 이용한 실제 반응형 레이아웃 검증. 실제 휴대폰 기기 테스트는 아님.
- 작은 화면에서 종이를 접고 방 좌우 이동 가능.
- 모바일 입력 중 인벤토리의 메모를 선택하면 메모가 열리고 입력창이 닫힘. 장치를 다시 열면 입력 중이던 `23`이 복원됨.
- 코드 문법: `node --check prototype/game.js`, `node --check prototype/room.js` 통과.
- 별도의 새 컨텍스트 리뷰에서 full-screen 구성 및 소스의 게임 진행에 대해 `ship` 판정. 지정된 이름의 리뷰어 역할 대신 일반 리뷰 에이전트 사용.

## 범위

Java 실행·AI 연결·서버 채점 기능은 포함하지 않는 HTML 인터랙션 시연입니다. 정답과 진행 상태는 브라우저에서 처리합니다. 그림은 외부 이미지 없이 Canvas로 직접 그립니다.
