# 기계실·온실 장면 분리

두 방 모두 소품을 배치한 완성 장면에서 시작한다. 완성 장면을 기준으로 움직이는 물체를 제거하고, 제거된 구역의 배경만 복원했다. 각 물체는 완성 장면의 원래 위치와 원근에서 잘라냈다.

- `master.png`는 완성 구도와 배치의 기준이다.
- `background.png`는 분리한 물체를 지운 1586×992 배경판이다.
- `layers.json`은 배경 원본 픽셀 기준 배치 좌표를 담는다.
- `layers/*.png`는 원래 접촉 그림자와 가려짐까지 복원하는 정위치 레이어다. 모든 레이어를 원래 위치에 합성하면 완성 장면과 픽셀 단위로 같다.
- `layers/*-movable.png`는 이동·회전용 투명 실루엣이다. 움직이는 동안에는 해당 정위치 레이어를 숨기고 이 파일을 사용한다. 레버나 발판을 다른 각도에서 볼 때는 필요한 상태 그림을 별도로 만든다.

온실은 씨앗함·표본·홈통·발판 두 장·운반차·부표를, 기계실은 배터리 다섯 개·압력계 바늘·레버 네 개·슬리브 세 개·문 걸쇠를 분리했다. 고정 선반, 배관, 난간, 벽에 매립된 단말은 배경에 남긴다.

## 인게임 배치 기준

전체 장면의 화면 맞춤과 클릭 좌표 변환은 인벤토리 영역 위에서 끝난다. 현재 인벤토리 78px, 하단 여백 16px, 장면과의 간격 8px을 합쳐 하단 102px을 예약한다. 넓은 창에서도 화면을 채우려고 위아래를 자르지 않는다. 작은 창과 넓은 창에서 각각 운반차의 손잡이와 기계실 피트의 레버 아래쪽까지 표시되는지 확인한다. 대사창이 인벤토리를 덮는 규칙은 기존과 같다.

이 폴더는 두 맵의 미술 작업본이다. 기존 플레이 중인 맵에서 이 배경과 소품을 사용하려면 새 클릭 영역, 퍼즐과 상태 변화를 연결해야 한다.
