# CODE ROOM · 자정의 기계실 재설계

## 콘셉트와 범위

기존 기계실의 정체성과 PDF의 다섯 미션을 유지한다. 플레이어는 지하 시설에 파견된 야간 엔지니어다. 오작동한 중앙 제어기가 출구를 잠갔다. 비상 전력을 복구하고 두 안전 계통을 정상화한 뒤, 현장의 실제 복구 결과를 중앙 장치에 연결해 퇴실한다. 빈 작업대 위에 장치 다섯 개를 늘어놓는 대신, 각 장치를 그 장치가 담당하는 설비에 붙인다.

**한 판은 코딩 3문제와 조작 게임 2문제다.** 코딩은 Java의 조건·반복 추적, 디버깅, 상태 전이를 푼다. 조작 게임은 공간 판단과 손맛으로 푼다. PDF의 네 자리 인증값과 기존 아홉 칸 입력기는 새 설계에서 사용하지 않는다. 미정이었던 긴급 미션의 시간 차감은 이번 초안에서 제외했다.

## 공간과 탐색 흐름

| 구역 | 물체와 설치 위치 | 입장 직후 |
| --- | --- | --- |
| 입구 왼편 전력실 | 독립 고정된 배터리 랙, 배터리 측면의 상태 꼬리표, 랙 옆 정비대에 고정된 차단기 | 꼬리표와 차단기를 조사할 수 있다. 작업등이 드문드문 깜빡인다. |
| 입구 오른편 배관 통로 | 벽에 고정된 배관, 움직이는 검침 손잡이, 하단 공구판의 차단 슬리브 | 배관의 서리와 흔들림을 살펴보고 공구를 들 수 있다. 구역 표시등은 전력 복구 후 켜진다. |
| 뒤쪽 분배실 | 분배함은 바닥 프레임 위에 설치한다. 작업표는 문 안쪽에 걸고, 제어 단말은 옆 콘솔에 고정한다. | 외부의 장비 명찰은 보인다. 단말은 전력이 돌아온 뒤 작동한다. |
| 아래쪽 압력 피트 | 고정 난간, 계기판, 서로 걸쇠로 물린 레버. 난간 아래를 들여다보면 레버 연결부가 보인다. | 난간에서 레버 연결부와 정비 기록을 조사할 수 있다. 제어기의 압력 시험은 안전해진 뒤 실행한다. |
| 출구 옆 중앙 제어기 | 출구 옆 벽에 매립한 제어기와 상태 표시 램프 세 개. 복구 증표는 물리 아이템이 아닌 장비의 상태 플래그다. | 장비 3곳의 실루엣과 출구가 보인다. 준비되지 않은 위치에는 해당 설비의 상태가 표시된다. |

전력 랙을 만져보거나 배관을 먼저 살펴볼 수 있다. **M1 뒤에 M2와 M3를 양쪽 순서로 풀 수 있으며**, 배관의 안전 상태와 분배기의 전력이 모두 확보되면 M4를 시험할 수 있다. M1~M4의 실제 상태가 M5에 모인다. 차단기나 피트를 미리 클릭하면 주변을 조사할 수 있고, 지금 작동할 수 없는 이유는 전력 표시나 물리적 잠금으로 읽힌다. 연구 단계의 내부 번호는 화면에 표시하지 않는다.

## 다섯 문제

| 문제·유형 | PDF에서 이어받는 미션 | 실제 플레이와 판정 |
| --- | --- | --- |
| **M1 비상 전력 · 코딩** | 모듈 상태와 전압을 읽어 전력 장치를 복구 | 테스트기 화면의 Java 반복문은 `state == OK && voltage >= 15`인 모듈만 연결 대상으로 삼는다. 랙의 A 17/정상, B 8/오류, C 29/정상, D 34/정상, E 11/정상 중 A·C·D를 물리 스위치로 연결한다. 마지막에 차단기를 올린다. 정확한 조합이면 작업등과 분배 단말이 켜진다. |
| **M2 구역 누출 차단 · 조작** | 가스 누출 구역을 찾아 차단 | 배관을 따라 검침 손잡이를 밀면 새는 연결부에 가까울수록 게이지가 움직이고 배관이 흔들린다. C의 이음쇠를 찾고 공구판에서 맞는 지름의 차단 슬리브를 끌어 끼운 뒤 손잡이를 돌려 고정한다. 다른 곳에 대면 맞물리지 않는다. 코드와 시간 벌점 없이 조작만으로 풀 수 있다. |
| **M3 전력 분배 · 코딩** | 우선순위와 70 이하 전력 조건의 두 오류 수정 | 분배함에서 명판을 읽고 콘솔의 Java 코드에서 두 군데를 교체한다. `Integer.compare(b.priority, a.priority)`는 오름차순 비교로, `used + power >= LIMIT`은 `> LIMIT`으로 고친다. ‘시험 실행’을 누르면 장비 투입 순서와 전력 막대가 움직인다. 고장 장비는 제외하고 EXHAUST 20 → PUMP 35 → LAMP 15가 합계 70으로 켜지면 성공이다. |
| **M4 압력 폭주 저지 · 조작** | 잠긴 레버를 올바른 순서로 작동 | 손잡이를 실제로 당기면 기계식 걸쇠와 가동 범위가 보인다. 위쪽 굵은 레버가 오른쪽 걸쇠를 풀고, 오른쪽이 아래쪽을, 아래쪽이 왼쪽을 자유롭게 한다. 한 번에 걸쇠 하나씩 움직이며, 시험 압력은 단계마다 내려간다. 틀린 레버는 당겨지지 않고 연결된 걸쇠가 덜컹거린다. PDF의 레버 순서 감각은 물리 연결부로 표현한다. |
| **M5 중앙 시스템 재가동 · 코딩** | 앞선 네 복구 결과를 사용해 출구 열기 | 단말에 들어온 신호는 `voltageOk`, `leakSealed`, `loadWithinLimit`, `pressureSafe`다. Java 상태 전이 부스에서 빈 조건 입력 포트에 신호선을 연결한다. 안전 점검 조건은 누출 차단과 압력 정상의 AND, 내부 가동 조건은 전압 정상과 허용 부하의 AND다. 두 조건이 모두 참이어야 `DOOR_RELEASED`로 진행한다. 단말은 신호를 하나씩 꺼 네 가지 실패 상태를 시험한다. 내부 가동 램프와 안전 점검 램프가 고장 계통에 맞게 꺼지고 문이 잠겨 있어야 한다. 네 신호가 모두 정상이면 양쪽 램프가 켜져야 한다. 성공하면 출구 걸쇠가 실제로 물러난다. |

### 현장 단서와 행동 표시

수첩에는 코딩에 필요한 기록 세 개만 남는다. 발견하면 즉시 기록을 펼치고 별도의 획득 대사를 재생하지 않는다. 어느 것부터 발견해도 된다.

| 구역 | 물체와 행동 표시 |
| --- | --- |
| 비상 전력 랙 | 랙 모서리에 고정된 **전력 기록**을 읽어 모듈 선택 기준을 확인한다. 모듈의 숫자와 상태는 장치에서 함께 읽는다. |
| 배관 통로 | 이음쇠와 슬리브에 같은 수의 줄이 찍혀 있고, 검침 손잡이를 움직이면 새는 구간에서만 바늘이 크게 뛴다. |
| 전력 분배함 | 문에 나사로 고정된 막대 그림 **분배표**에서 우선순위와 용량 조건을 읽는다. |
| 압력 피트 | 노출된 손잡이 핀과 연결된 걸쇠가 다음 조작을 알려 준다. 막힌 레버를 당겨도 이미 풀린 상태는 유지한다. |
| 중앙 제어기 | 문 옆 체크 표시 금속 **점검표**에서 신호 분류를 읽는다. 시험 결과는 제어기의 가동·안전 상태로 확인한다. |

## 시간 경과가 설비에 남기는 변화

공통 제한시간 중 **경과한 비율**을 기준으로 한다. 아래 초는 기존 180초 제한을 적용했을 때의 예시다. 플레이어는 시작할 때 정상 기준을 볼 수 있다. 이후 같은 위치의 자침, 배관, 걸쇠가 바뀌므로 다른 구역을 조사하고 돌아와도 시간이 흘렀다는 차이가 보인다.

| 경과 | 방 전체에서 보이는 변화 | 장치 가까이에서 보이는 변화 |
| --- | --- | --- |
| 시작 | 출구의 안전 걸쇠가 닫혀 있고 배관 통로에 가벼운 진동이 있다. 랙의 축전지는 일부만 켜져 있다. | 압력 피트의 자침은 상승 눈금 초입에 있다. 계기판에는 정상·주의·한계가 모양과 눈금으로 구분돼 있다. |
| 25% · 45초 | 미복구 전력실의 작업등이 한 번씩 떨리고, 누출 이음쇠 근처부터 성에가 퍼진다. | 누출이 있는 계통의 바늘 진폭이 커지고, 연결부에 매단 정비 리본이 움직인다. |
| 50% · 90초 | 미정상 피트의 배출구가 흰 증기를 짧게 내뿜는다. 배관을 봉인했다면 오른쪽의 진동은 잦아들고 피트 쪽 변화만 남는다. | 압력 자침이 주의 눈금으로 들어가고, 아직 풀리지 않은 레버의 걸쇠가 주기적으로 떨린다. |
| 75% · 135초 | 출구 위 물리 경고등이 천천히 돌고, 실내 케이블에 그림자가 지나간다. 미정상 피트의 증기 간격이 짧아진다. | 제어기에는 ‘정상화한 계통은 안정, 미복구 계통은 경고’가 각 램프 옆의 실제 상태 표찰로 구분된다. |
| 만료 | 중앙 보호 차단기가 떨어지고 출구의 보조 안전 걸쇠가 내려온다. 짧게 결과 화면으로 이어진다. | 퍼즐을 조작 중이면 입력을 종료하고 가장 가까운 설비의 전원이 꺼지는 모습을 보여준다. |

**풀이 결과가 환경 변화를 이긴다.** M1을 해결하면 작업등이 안정되고, M2를 해결하면 새는 이음쇠의 리본과 성에 진행이 멈춘다. M4를 해결하면 압력 자침이 정상 범위로 돌아가며 증기가 멈춘다. 다음 시간 구간에 들어가도 해결한 계통은 다시 고장 나지 않는다. 출구의 경고등은 남은 시간이 얼마 없는 동안 방 전체에서 읽을 수 있는 공통 신호다.

정비실을 왕복하며 경고가 어디서 시작해 어디까지 번졌는지 느끼게 한다. 경고 변화로 단서나 클릭 영역을 가리지 않으며, 소리 없이도 자침·리본·램프 회전으로 구간 차이를 읽을 수 있게 한다.

## 먼저 검증할 것

1. 입구에서 전력과 배관 중 어느 쪽으로 가도 조사할 만한 물체가 보이는가.
2. M1 후 M2→M3, M3→M2가 모두 가능한가. 먼저 본 증거가 뒤에서도 유효한가.
3. M2에서 게이지로 위치를 찾고 슬리브를 실제로 끌어 끼우는 과정이 즉각 반응하는가.
4. M3에서 우선순위만 고치거나 경계값만 고치면 서로 다른 실패가 보이는가.
5. M4에서 한 레버가 움직이면 다음 걸쇠가 실제로 풀리고, M5에서 오동작 검증을 통과해야 문이 열리는가.
