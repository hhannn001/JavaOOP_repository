# CODE ROOM · 새벽 온실의 마지막 씨앗

## 적용 범위

기계실은 기존 맵의 정체성과 다섯 미션을 이어받아 별도로 [재설계한다](기계실_재설계.md). 새로 설계할 맵은 **새벽 온실의 마지막 씨앗** 한 곳이다. 온실은 독립적으로 입장하고 탈출하며, 필수 퍼즐은 **코딩 3개(G1·G4·G5)와 조작 게임 2개(G2·G3)**다. 기존 4자리·9자리 숫자 암호를 사용하지 않는다.

## 이야기와 목표

플레이어는 온실의 야간 당직 실습생이다. 폭우에 운반 통로의 저지대가 잠겼고, 아침에 외부로 옮겨야 할 희귀 씨앗도 온실에 남았다. 물길을 되살리고 발판과 레일을 연결해 씨앗을 높은 출구까지 운반한다. 조작할 때마다 물 높이, 이동 가능한 구역, 운반차의 균형이 달라진다.

## 공간과 퍼즐

### 첫 장면과 공간 배치

젖은 현관에서 높은 동쪽 문을 본다. 문 앞까지 이어지는 철제 레일이 물에 잠겼고, 빈 운반차가 레일 시작점에서 덜컹거린다. 왼쪽 건조한 작업대 위에 식물 표본과 씨앗 서랍이 있고, 오른쪽 물받이 뒤로 끊어진 물길이 보인다. 첫 조사 지점은 **마른 작업대**와 **붉은 수위선이 보이는 물받이**다.

| 실제 장소 | 놓을 물체와 지지면 | 플레이어가 이동하는 이유 |
| --- | --- | --- |
| 왼쪽 마른 작업대 | 표본은 메쉬 건조대에 걸고 이름표는 화분 꽂이에 세운다. 씨앗함은 작업대 서랍에 붙어 있다. | 표본 확인과 운반할 씨앗 확보 |
| 오른쪽 물받이 | 물받이는 창 아래 벽에 고정한다. 빗물 홈통은 작업대 테두리에 나사를 박아 붙이고 바닥에 예비 홈통을 쌓아 둔다. | 물길을 연결하고 저지대의 수위 변화 관찰 |
| 가운데 저지대 | 레일은 바닥에 고정한다. 부유 발판 두 장은 물이 빠지면서 받침턱과 높이가 맞는다. | 발판을 옮겨 끊어진 레일 복원 |
| 동쪽 출구 | 운반차는 레일 위에, 균형 자침은 차축 위에 단다. 출구는 바닥보다 높은 문턱 위에 둔다. | 무게를 맞춘 뒤 실제로 운반차를 밀어 탈출 |

흐름은 **마른 작업대[G1] ↘ / 물받이[G2] ↘ → 저지대의 레일[G3] → 운반차 적재[G4] → 동쪽 분기 레일[G5]**다. G1과 G2는 병행할 수 있다. G2가 G3의 접근을 열고, G1과 G3의 결과가 G4에 합쳐진다. 물이 빠지면 새로 드러난 레일·받침턱을 멀리서도 알아볼 수 있게 한다.

### 문제 5개

| ID · 방식 | 찾을 증거와 플레이어의 행동 | 판정과 방의 변화 |
| --- | --- | --- |
| **G1. 밤에 남긴 표본 · 코딩, 조건 필터** | 작업대의 Java 선별기를 읽는다. `leaf == ROUND && !damaged && stamp == WAVE`를 만족하는 후보만 집게로 골라 씨앗 트레이에 꽂는다. | 둥근 잎·정상·파도 표식이 모두 일치하는 한 봉투가 정답이다. 둥근 잎이지만 손상된 봉투와 건강하지만 삼각 표식인 봉투는 제외된다. 맞는 봉투를 상자에 담아 보관함에서 꺼낸다. |
| **G2. 넘치는 물받이 · 조작, 물길 시험** | 경사 홈통 3개를 돌리고 연결부 사이에 끼운 다음, 손잡이를 당겨 적은 물을 흘린다. 물을 따라가며 어느 이음쇠에서 새는지 확인한다. | 위 유입구 → 중앙 이음쇠 → 왼편 빈 화분으로 물이 이어져야 한다. 막힌 곳에서는 거품과 물방울이 튄다. 틈이 없으면 저지대의 물이 빠지고 부유 발판이 낮아진다. 코드 없이 눈으로 흐름을 읽는다. |
| **G3. 레일 위 발판 · 조작, 슬라이딩 공간 퍼즐** | 물받이 아래 정비 그림에 발판이 레일 방향으로 움직이는 모습이 그려져 있다. 발판 두 개를 직접 끌어 통로의 두 틈을 메운다. | 위쪽 가로 발판이 중앙 세로 발판의 이동로를 막고 있다. 가로 발판을 오른쪽 받침으로 밀고 세로 발판을 아래 받침에 내리면 홈이 이어진다. 운반차 바퀴가 통과할 수 있게 된다. |
| **G4. 기울지 않는 짐 · 코딩, 식과 변수 추적** | 운반차 펌웨어의 `left = seedWeight * leftDistance;`와 `right = weight * distance;`를 읽고 `left == right`가 되는 실제 추와 받침을 골라 장착한다. 자침은 조작에 바로 반응한다. | 상자 무게 2, 왼쪽 거리 1이다. 오른쪽 받침 거리는 1·2, 추 무게는 1·3이다. 무게 1의 추를 오른쪽 거리 2에 둘 때만 균형이 맞는다. 한 번에 추 하나만 장착할 수 있다. |
| **G5. 새벽 운반 · 코딩, 분기 추적** | 다리 옆 Java 운반 규칙과 난간의 안내도를 대조한다. `if (flooded) takeHighTrack();` 이후 `if (bufferAhead) takeDoorBranch();`가 실행될 지점을 지도에서 찾고, 실제 레일 전환기 두 개를 조작해 시운전한다. | 첫 분기에서 침수 표식이 있는 직진선을 피해 높은 레일로, 두 번째에서 정지턱을 피해 출구 쪽 레일로 보낸다. 운반차는 분기 전에 정차한다. 잘못된 갈래에서는 바로 전 분기로 되돌릴 수 있다. |


**대표 장면 · G3 발판 미끄러뜨리기.** 발판이 포인터를 따라 움직이되 가이드 레일은 이탈할 수 없다. 옆 발판과 닿는 위치에서 멈추고 손을 놓으면 가장 가까운 받침에 고정된다. 경로가 열리는 순간, 뒤쪽의 실물 레일 홈이 한 줄로 이어진다. 키보드로 발판을 선택하고 방향키로 밀 수 있다. 문제 도중 방으로 돌아가도 발판 위치를 기억한다.

## 현장 단서와 행동 표시

수첩에 남는 기록은 작업대의 **표본표**, 적재대 방향 선반의 **균형표**, 출구 계단의 **레일 지도** 세 개다. 위치가 다른 기록을 먼저 읽어도 풀이가 잠기지 않는다. 기록을 조사하면 대사 없이 펼쳐지고, 대사창 유무와 관계없이 같은 크기로 놓인다.

| 구역 | 물체와 행동 표시 |
| --- | --- |
| 마른 작업대 | 이미 놓여 있는 식물 표본이 선별기에 필요한 기록이다. 씨앗함과 표본은 각각 별도 조사 대상이다. |
| 오른쪽 물받이 | 출수구에 붙은 물길 화살표를 따라 홈통을 연결한다. 시험 중에는 연결부의 열린 쪽과 물이 새는 위치를 본다. |
| 저지대 발판 | 배수 뒤 드러나는 가로 홈과 받침의 화살표가 슬라이드 방향을 보여준다. 다른 발판이 걸리면 움직이지 않는다. |
| 운반차 | **균형표**에서 계산식을 읽고, 받침과 추의 표식 및 설치 후 자침으로 균형을 확인한다. |
| 분기 레일 | 계단 옆의 **레일 지도**는 갈라지는 방향을 그린 기록이다. 침수 구간과 정지턱은 시운전에서 직접 확인할 수 있다. |

씨앗 선별과 배수는 서로 독립적으로 진행한다. 배수가 끝나면 씨앗이 없어도 저지대의 발판을 움직일 수 있다. 두 갈래가 운반차 적재 단계에서 합쳐진다.

## 방탈출 감성을 만드는 제작 기준

- **왜 거기 있는가부터 확인한다.** 물체마다 받치는 면이나 고정점을 먼저 정하고, 그 뒤에 에셋과 클릭 범위를 잡는다. 상자는 선반에 무게가 실리고, 로프는 도르래에 걸리며, 발판은 물의 높이에 반응한다. 방 전체 뷰와 근접 뷰에서 접지면·그림자·가려짐의 방향이 맞아야 한다.
- **물체를 동선에 배치한다.** 입구에서 보이는 단서, 몸을 돌려야 보이는 장치, 풀이 후 새로 드러나는 영역을 구분한다. 처음부터 전부 같은 높이로 늘어놓지 않고, 첫 클릭 후보는 두 곳으로 좁힌다.
- **막혔을 때는 물증으로 안내한다.** 작업대의 물때 자국과 보수 표식이 힌트가 된다. 물체를 조사한 경우 수첩에서 다시 본다. 단계마다 새 힌트가 팝업으로 뜨는 흐름은 쓰지 않는다.
- **퍼즐 화면과 방의 상태를 연결한다.** 낮아진 수위, 움직인 발판, 열린 문은 근접 화면을 닫아도 남는다. 맵을 재시작하면 초기 상태로 돌아온다.
- **조작이 무엇을 했는지 바로 보여준다.** 홈통을 돌리면 물길이 바뀌고, 물을 흘리면 막힌 곳에서 넘친다. 결과는 색상에 더해 움직임이나 아이콘으로도 표현한다. 조작할 수 없는 물체는 확대 없이 현재 상태를 인지할 수 있게 한다.
- **코드의 사고방식을 맵 안에 남긴다.** 온실은 조건에 따른 물의 흐름과 운반차의 균형이 중심이다. 발표에서 Java 학습 연결이 필요하면 탈출 결과에 ‘내가 작동시킨 규칙’을 짧은 의사 코드로 덧붙인다. 본편에서 코드는 정답 입력으로 강제하지 않는다.
- **시간은 온실의 물체에 드러난다.** 물받이, 부유 발판, 출구 가까이의 물건을 통해 위험 수위를 읽는다. 운반차는 분기 앞에서 멈추므로 경로를 보고 판단할 수 있다.

## 시간 경과가 온실에 남기는 변화

기계실이 압력과 진동으로 조여 온다면, 온실은 **빗물이 실제로 어디까지 들어왔는가**로 시간을 보여준다. 아래 초는 180초 예시다. 유리창에 비친 수면과 기둥의 물때선, 떠오르는 물체가 같은 방향으로 변해야 한다.

| 경과 | 배수 전의 온실 | G2로 배수한 뒤 |
| --- | --- | --- |
| 시작 | 가운데 레일 일부가 잠겨 있고, 왼쪽 작업대까지 이어지는 마른 통로가 있다. 물받이 아래 빈 화분에 빗물이 떨어진다. | 배수 홈통으로 물이 빠지고 잠겼던 받침턱이 드러난다. 발판은 레일 높이까지 낮아진다. |
| 25% · 45초 | 저지대 기둥의 첫 물때 눈금까지 찬다. 물 위의 빈 화분 받침이 떠올라 레일 옆에 닿는다. | 저지대는 낮아진 수위를 유지한다. 창밖 빗줄기는 두꺼워지고 유리의 물방울이 빨라진다. |
| 50% · 90초 | 물이 레일의 나사 머리를 덮고 물결에 빈 화분 받침이 흔들린다. 작업대 바닥에 물빛이 비친다. | 연결한 홈통은 계속 물을 빼고 있다. 출구 바깥 집수통의 부표가 두 번째 홈까지 올라간다. |
| 75% · 135초 | 저지대 수위가 난간 밑 마지막 물때선에 닿는다. 빈 화분 받침이 난간 줄에 걸려 더 멀리 떠가지 않는다. | 집수통 부표가 높은 출구 옆의 기계식 깃발을 들어 올린다. 출구 외부의 위험이 가까워졌다는 표시다. 연결한 레일과 놓은 발판은 마른 상태를 유지한다. |
| 만료 | 바깥 물이 한계선에 닿고 출구의 방수문이 내려온다. 안쪽 물이 차오르는 짧은 장면 뒤 결과를 보여준다. | 집수통 부표가 끝까지 올라가 출구의 방수문을 내린다. 배수에 성공했어도 외부 집수통은 계속 차오르므로 종료 원인이 화면에서 읽힌다. |

**수위의 변화와 퍼즐 진행을 분리한다.** 배수가 되면 실내 저지대는 다시 잠기지 않는다. 배수 전에도 물이 최대 어디까지 오를지는 물때선으로 예고하고, 실내의 필수 단서·아이템·마른 접근로는 가리지 않는다. 배수 이후에는 외부 집수통이 같은 제한시간의 압박을 전달한다. 조작 중에도 대상 뒤의 수면이나 집수통 부표가 보이도록 근접 구도를 잡는다.

## 제작 순서와 검증

1. **완성 구도로 공간 검증** · 소품까지 놓은 온실 전체 장면에서 입구 화면, 근접 조사 지점, 물체의 지지면을 검증한다. 같은 구도에서 배경판과 투명 오브젝트를 분리한다. 첫 화면에서 막힌 출구와 조사 후보 두 곳이 모두 보여야 한다.
2. **대표 게임부터 조작 검증** · 발판을 실제로 끌어 옮기고 다른 발판에 막히는 조작을 먼저 만든다. 별도 설명 없이 플레이어가 첫 행동을 시도하는지 관찰한다. 오답 직후 화면만 보고 다음 시도를 할 수 있어야 한다.
3. **의존 관계와 상태 검증** · 표본 분류와 물길 조립을 양쪽 순서로 시험한다. 장소 이동, 근접 화면 닫기, 오답 뒤에도 진척과 물체 상태가 유지되는지 확인한다.
4. **다섯 문제와 장면 통합** · 분리한 배경과 에셋을 연결하고 온실의 이동을 처음부터 끝까지 통과한다. 제작 단계에서 실제 클릭 좌표, 초회 풀이 시간, 목표 해상도를 확정한다.
5. **첫 플레이 관찰** · 온실을 처음 보는 플레이어 3명을 대상으로 첫 조사 위치, 1분 이상 멈춘 곳, 단서와 행동을 연결한 순간을 기록한다. 최소 2명이 구두 안내 없이 첫 퍼즐을 시작하고, 발판 퍼즐에서 최소 2명이 오답 후 스스로 다시 시도하는 것을 초기 기준으로 삼는다. 기준을 못 채우면 미술을 더 추가하기 전에 배치·피드백·설명을 수정한다.
