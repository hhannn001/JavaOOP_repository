# CODE ROOM 프로젝트 기획서

## 프로젝트 제목

**CODE ROOM: Java 코드 방탈출 게임** (가제)

## 프로젝트 설명

Java Swing으로 만드는 2D 데스크톱 방탈출 게임이다.
사용자는 로그인 후 포스터형 맵 선택 화면에서 방에 입장한다.
코드 종이의 실행 결과를 추리해 서랍과 3×3 다이얼을 풀고, 얻은 열쇠로 탈출한다.
클리어 여부와 최고 기록은 사용자별로 로컬 SQLite에 저장한다.

## 프로젝트 목표

3주 안에 맵 1개와 Java 코드 퍼즐 2개를 포함한 MVP를 완성한다.
로그인 → 맵 선택 → 단서 수집·암호 입력 → 탈출 결과까지 끊김 없이 진행되게 한다.
FSD 방식으로 기능별 책임을 나눠 7명이 병렬 개발하고, 통합 후 QA 오류를 빠르게 수정한다.

## 데이터 구성

| 데이터 이름 | 데이터 설명 | 예상 개수 |
| --- | --- | --- |
| 사용자 (`users`) | 시연 계정의 로그인 정보와 비밀번호 해시 | 초기 3개 |
| 맵 (`maps`) | 포스터·학습 주제·플레이 가능 여부 | 3개: 플레이 가능 1개, 준비 중 2개 |
| 퍼즐 (`puzzles`) | 코드 종이·정답 형식·정답·힌트·진행 순서 | 2개 |
| 클리어 기록 (`clear_records`) | 사용자·맵별 클리어 여부와 최고 탈출 시간 | 초기 0개, MVP 기준 최대 3개 |

## 팀 규칙 및 회의

담당 기능별 파일을 소유하고, 공통 인터페이스 변경은 구현 전에 팀에 공유한다.
작업은 기능 단위 PR로 올리고 담당자가 검증한 뒤 다른 팀원이 리뷰한다.
수업 후 짧게 진행 상황과 막힌 점을 공유하며, 주 1회 전원이 가능한 날짜에 통합 회의를 연다.
그 외에는 메신저와 PR에서 실시간으로 질문·피드백을 주고받는다.

## 진행 일정
