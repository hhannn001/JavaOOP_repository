실행 환경은 macOS의 JDK 20.0.2이며 컴파일 대상은 `pom.xml`의 Java 17(`release=17`)이다. CI의 JDK 17 실행 결과를 이번 로컬 실행으로 대신하지 않는다.

일반 명령은 `./mvnw -Djava.awt.headless=true clean verify`다. 이번 환경에서는 기본 Maven 캐시 잠금 파일 쓰기가 제한되어 기존 캐시를 임시 경로로 복사한 뒤 다음 명령으로 실행했다. 저장소의 Maven 설정은 바꾸지 않았다.

```sh
./mvnw -o -Dmaven.repo.local=/tmp/coderoom-doc-refresh/maven-repository -Djava.awt.headless=true clean verify
```

임시 캐시 경로는 이 세션용이며 다른 환경에서 그대로 사용할 필요가 없다. 세부 JUnit 결과는 재실행 시 `target/surefire-reports/`에 생성된다.
