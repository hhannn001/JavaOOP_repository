# 로비 고양이

Java Swing `DashboardCat`, `CatReactionFrames`, `DashboardBell`에서 사용한다.

- `cat-atlas.png`: 4×3, 대기·눈 깜빡임·기존 걷기·점프 준비/상승/하강/착지.
- `cat-walk.png`: 4×3, 가까운 발은 크림색, 먼 발은 갈색인 걷기 12장. 재생 순서는 `WALK_ORDER`에 있다.
- `cat-rest.png`: 4×3 중 마지막 행의 앉은 자세·눈 깜빡임을 휴식에 사용한다. 천천히 호흡하는 움직임을 함께 적용한다.
- `stand-grumpy.png`: 4×4, 상단 8장은 두 발로 일어서기, 하단 8장은 짜증.
- `love-curious.png`: 4×4, 상단 8장은 눈웃음, 하단 8장은 호기심.
- `sleepy-shy.png`: 4×4, 상단 8장은 졸림, 하단 8장은 부끄러움.
- `surprise-stretch.png`: 4×4, 상단 8장은 놀람, 하단 8장은 기지개.
- `bell.png`: 투명 배경 호출 종.
- `counter-clean.png`: 종을 지운 배경 참조. 전체 배경을 교체하지 않고 종이 있던 58×56 영역만 합성한다.

색상은 생성 원본 그대로 사용한다. 이전 갈색 조명 보정은 제거했다. 시트의 기본 서 있는 자세를 기준으로 배율을 맞추며 앉거나 꼬리를 말아도 다시 확대하지 않는다. 표정마다 8장의 원화를 동일한 발 기준선에 맞추고 자세의 높이 차이는 투명 여백으로 처리한다. 전환 중 그림을 늘이거나 줄이지 않으며, 얼굴이 겹치지 않도록 크로스페이드 없이 한 자세만 그린다. 시작/종료는 공통 기본 자세이며, 중간 구간은 smoothstep으로 재생한다. 클릭 반응은 2.4초이며 연타로 재시작하지 않는다. 방향키 입력과 종 호출은 반응을 중단할 수 있다. 클릭 점프는 없으며 ↑ 키의 물리 점프는 유지한다.

기본 이동은 16ms Swing 타이머와 경과 시간 기반 가감속을 사용한다. 로비 좌표 x=230…1350 안에서만 이동하며, 자동 산책은 최소 360픽셀 떨어진 목적지까지 걸은 후 쉰다. 입력이 4초 없으면 자동 산책으로 돌아간다. 종을 누르면 x=1280까지 달려와 일어선다. 화면 숨김 시 타이머가 정지하고 창 포커스를 잃으면 입력을 해제하고 일시정지한다.

휴식은 4~7초이며 감정 동작 시간도 포함한다. 휴식 중 한 번, 1.5~3초 후 기지개(30%)·졸림(40%)·눈웃음(30%)을 선택한다. 동작이 진행 중이면 완료한 뒤 출발하므로 최대 약 1.5초 연장될 수 있다. 산책 중에는 5~8초 간격으로 자동 점프를 35% 확률로 시도하며, 점프 후 10초 쿨다운을 둔다. 휴식·수동 조작·종 호출·감정표현 도중에는 자동 점프를 시도하지 않는다. 고양이는 Press Enter 화면부터 보이고 움직이며 클릭과 방향키 입력도 받는다.

## 생성 이력

내장 `image_gen`으로 사용자가 승인한 치즈색 픽셀 고양이 시안을 참조해 생성했다. 원본 프롬프트의 공통 조건은 다음과 같다.

> Same cream and honey ginger pixel cat, big round-square head, short legs, curled tail, dark chocolate stepped outline. True transparent background. Equal regular grid, identical character scale and pixel density, facing right, planted paws on the same baseline. No labels, floor, grid lines or cast shadows.

걷기는 네 발 교차와 가까운/먼 발의 명도 구분을 요청했다. 감정 시트는 각 8장으로 기본 자세 → 중간 자세 → 감정 표현 → 기본 자세의 순서를 요청했다. 종은 로비 원본의 황동 종을 투명 배경으로 분리하고, 별도 생성에서 원본 배경의 종 부분만 지우도록 요청했다.

검증: 실제 스프라이트 픽셀에서 양쪽 앞발·뒷발의 앞뒤 순서 교환, 이동 경계와 장거리 산책, 종 도착/중단, 감정 8종 순환, 클릭 시 비점프, 프레임 간 변화량과 발 기준선, 공통 기본 자세 복귀를 테스트한다.
