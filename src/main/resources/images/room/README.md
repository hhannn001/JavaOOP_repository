# 방 리소스

담당 D. 방 배경과 서랍·다이얼·문 상태 이미지를 배치한다. 그리기 좌표와 클릭 영역의 기준 크기를 맞춘다.

## 파일

| 파일 | 언제 보이나 | 설명 |
| --- | --- | --- |
| `study_locked.png` | 항상(바탕) | 시작 상태 방 배경. 1586×992 |
| `drawer_open.png` | 서랍 해제 이후 (DRAWER_OPEN, SAFE_OPEN, ESCAPED) | 서랍이 당겨져 나오고 안에 종이가 보인다 |
| `dial_solved.png` | 다이얼 해제 이후 (SAFE_OPEN, ESCAPED) | 다이얼 버튼 9개가 초록색으로 켜진다 |
| `door_open.png` | 탈출 (ESCAPED) | 문이 열리고 밝은 빛이 들어온다 |

## 덧그림 규칙

- 단계별 그림 3장은 `study_locked.png` 위에 포개 그리는 **투명 PNG**이며, 크기는 배경과 같은 1586×992다.
- 바뀌는 부분만 불투명하게 그리고 나머지는 투명으로 둔다. 단계가 올라가면 앞 단계의 덧그림도 함께 보인다.
- 파일 이름은 코드(`RoomPanel`의 `Layer`)와 같아야 한다. 크기가 다르면 배경 크기에 맞춰 늘려서 겹친다.
- 현재 3장은 `study_locked.png`를 이미지 처리해 만든 **임시 그림**이다. 정식 그림이 나오면 같은 이름·같은 크기로 덮어쓰면 코드를 고칠 필요가 없다.
- 덧그림이 클릭 영역(`RoomPanel`의 `HOTSPOTS`) 바깥으로 크게 번지지 않게 한다. 서랍·다이얼·문의 영역은 코드의 숫자를 함께 확인한다.
