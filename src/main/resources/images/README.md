# 테스트용 이미지 에셋

프로토타입의 녹색 서재·황동·목재 색상에 맞춘 GPT Image 생성 이미지다. UI 문구와 정답은 이미지에 넣지 않았다. Swing에서는 클래스패스의 `/images/...` 경로로 읽는다.

| 파일 | 화면 / 담당 | 용도 |
| --- | --- | --- |
| `posters/room01_last_compile.png` | 맵 선택 / C | 플레이 가능한 서재 맵 포스터 그림 |
| `posters/room02_missing_notes.png` | 맵 선택 / C | 준비 중인 연구실 맵 포스터 그림 |
| `posters/room03_stopped_machine.png` | 맵 선택 / C | 준비 중인 기계실 맵 포스터 그림 |
| `room/study_locked.png` | 방 / D | 시작 상태 배경. 서랍·3×3 다이얼·문에 별도 클릭 영역을 얹는다 |
| `inventory/brass_key.png` | 인벤토리 / F | 열쇠 아이템 그림. 배경 투명 |
| `clue/blank_note.png` | 단서 / F | 내용 없는 종이. Java 코드와 힌트는 UI에서 렌더링. 배경 투명 |

포스터는 1024×1536, 방 배경은 1586×992, 열쇠는 1536×1024, 종이는 1024×1536 PNG다. 화면에 맞게 축소하되 방 이미지와 클릭 영역은 같은 비율로 변환한다. 준비 중 표시는 이미지가 아니라 맵 카드 상태로 처리한다.

이 이미지는 화면 배치·스케일링 테스트용이다. 실제 퍼즐 상태별 그림으로 사용하려면 열린 서랍, 해제된 다이얼, 열린 문 이미지가 추가로 필요하다. 배경 이미지의 서랍에는 여러 숫자 장식이 있으므로 실제 네 자리 입력 UI와 혼동되지 않도록 클릭 영역에 명확한 라벨을 붙인다.
